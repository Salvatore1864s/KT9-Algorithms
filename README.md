# KT9 — Практикум по алгоритмам

Шесть решений на Java.

## Задачи

1. **Task1** — минимальное разбиение строки на палиндромы.
2. **Task2** — количество путей по сетке с препятствиями.
3. **Task3** — максимальный вес независимого множества в дереве.
4. **Task4** — минимальная стоимость объединения соседних групп (интервальное DP).
5. **Task5** — максимальная сумма пути по сетке с ограниченным числом применений экрана.
6. **Task6** — максимальная сумма связного подмножества ровно из k вершин дерева.

## Компиляция и запуск

Из корня проекта:

```bash
javac src/Task1.java
java -cp src Task1
```

Для остальных задач замените `Task1` на `Task2`, `Task3`, `Task4`, `Task5` или `Task6`.

## Сложность

- Task1: O(n²) времени и памяти.
- Task2: O(nm) времени, O(m) дополнительной памяти.
- Task3: O(n) времени и памяти.
- Task4: O(n³) времени, O(n²) памяти.
- Task5: O(nm(k + 1)) времени, O(m(k + 1)) памяти.
- Task6: O(nk²) времени в худшем случае, O(nk) памяти.
